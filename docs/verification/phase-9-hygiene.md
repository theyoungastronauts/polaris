### Task 8 — multi-frontend guard (item 4, verified)
`_merge_profiles` now tracks `seen_lines` parallel to `seen_keys`. Key derivation is correct in **both** loops (main stack loop and `_multi-stack` loop): plain path → `key="$line"`; `cmd:` line → `key="${line%%=*}"` (e.g. `cmd:react`). The conflict only fires when `line == cmd:*` **and** `seen_lines[$i] != line` — i.e. same command key mapping to a different full line (different file). Behavior:
- Same cmd key + **same** file (identical line, e.g. every nextjs variant's `cmd:react=…react-best-practices.md`) → `!=` is false → no conflict, deduped. **No false positive.**
- Same cmd key + **different** file (e.g. `cmd:nextjs-bootstrap` → mui vs shadcn bootstrap) → conflict, `err` naming both files + `exit 1`.
- Plain-path duplicate (e.g. `agents/executor.md`) → not `cmd:*`, conflict branch skipped → deduped silently.
Matches the lead's live test (`--stack nextjs-mui --stack nextjs-shadcn` → exit 1 naming both bootstrap files).
